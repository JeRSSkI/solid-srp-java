# Single Responsibility Principle (SRP)

## Опис
Принцип єдиної відповідальності означає, що кожен клас повинен виконувати лише одну функцію
та мати одну причину для змін.

## Приклад
У цьому репозиторії показано приклад правильного застосування SRP:
- User — зберігає дані користувача
- UserRepository — відповідає за збереження в базу даних
- EmailService — відповідає за відправку email
